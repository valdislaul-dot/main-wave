# Plan 02-01 — Read-only state passthrough (STA-01) + defensive read layer (STA-03) + /health/ready (HLT-02)

## Phase Goal (MVP framing, derived from the ROADMAP Goal line)

**As a** consumer of gogo's live state (cloud panel, external script, future trigger tooling), **I want to** GET market/auction/zt-pool state over HTTP as the exact JSON bytes the pipeline wrote, with freshness headers I can poll on, and be certain I never receive a torn or half-written file even while the pipeline is mid-write, plus a readiness endpoint that tells me only whether the files are there — **so that** I can rely on gogo's state remotely without ever touching `data/` directly or guessing at staleness.

> Note: the ROADMAP Phase 2 Goal line is prose, not user-story form; the story above is a word-level framing of that locked goal plus D-01..D-05 (user-signed in /gsd-discuss-phase).

<objective>
Deliver the whole Phase 2 scope on the Phase 1 `api/` package: one new module `api/state.py` (STA-01/STA-03/HLT-02) holding the D-03 whitelist map, the defensive read layer (per-request binary open→read→fstat→close, JSONDecodeError short retry on fresh snapshots, per-name in-process last-good cache served with `X-Data-Stale: true`), and the two route families — `GET /v1/state/{name}` (verbatim bytes + `X-Data-Mtime`/`X-Data-Age-S`, per D-01/D-02/D-05) and `GET /health/ready` (stat-only existence/readability, 200/503, never data age, per HLT-02); a one-line router registration in `api/main.py`; and the full `tests/test_state.py` contract suite (STA-01/STA-03/HLT-02/SC4 + the threaded 0×5xx hammer). The plan ends with the resident service on 127.0.0.1:8000 restarted onto the new code and live-probed, the SC4 grep audit run, the full pytest suite green, and the real-pipeline-run 0×5xx observation handed to the user as the end-of-phase human check.

Phase 3 (triggers) and Phase 4 (STA-02 data classification) build on this module's whitelist/cache seam; the milestone constraint "never modify a pipeline file" is respected throughout (read-side defense only, per RESEARCH Don't-Hand-Roll).

Output: `api/state.py`, a two-line change to `api/main.py`, `tests/test_state.py`, green full suite, and a live resident service serving the new endpoints on 127.0.0.1:8000.

- STA-01 (encoding — unresolved): byte identity is the contract — the verbatim CRLF test pins that equality means byte equality (`response.content == fixture_bytes`), not JSON equality, so UTF-8/CRLF/indent/key order all round-trip untouched (D-02, RESEARCH Pitfall 1).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Probe client → GET handlers | The only input is the `{name}` path parameter (no query/body/header input consumed); whitelist resolution decides whether a request reaches the filesystem at all |
| data/ filesystem → read layer | Files are written by separate pipeline processes (atomic os.replace and direct truncate-writers) — content crosses into the API process untrusted and possibly mid-write |
| Read layer → consumer | Served bytes + freshness headers + (fallback only) the stale flag become the consumer's view of gogo's trading state — a torn body or lying header propagates as wrong state |
| In-process cache → handlers | _CACHE holds the last-good payload per name; it is process-local and cold after restart by design |
