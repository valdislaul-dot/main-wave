# Plan 01-01 — api/ package: /health liveness + fail-closed boot + first pytest suite

## Phase Goal (MVP framing, derived from the ROADMAP Goal line)

**As a** load-balancer probe / external consumer, **I want to** GET /health from a resident FastAPI service that boots on the Windows machine, auto-starts after reboot, and refuses to start exposed without a token, **so that** gogo's liveness can be verified at any hour without ever touching pipeline state files.

> Note: the ROADMAP Phase 1 Goal line is written in prose form, not user-story form; the story above is a word-level framing of that locked goal plus the D-08 probe contract. A `/gsd mvp-phase 1` pass could restate it canonically.

<objective>
