## 数据源黑名单

| 数据源 | 问题 |
|--------|------|
| **baostock** | 当日数据17:30后才就绪, 08-14/08-17反复延迟出错致79/92只评分失败, 2026-08-17彻底移除 |
| **mootdx** | 成交量数值与腾讯/同花顺不一致, 导致量比计算偏差, 回测结果不可信(-99.8%) |

## 规则

- K线主库口径基准 = 搜狐不复权 (kline_data/ + backtest_kline/); 每日追加行允许前复权(腾讯qfq), 复权混存由文件 metadata.adjustment 显式记录
- 新数据源接入前必须交叉验证: 同一股票同一日期的 O/H/L/C/V 与库存 kline_data 对比 (5只×5个日期)
- 数据不一致的源直接弃用, 不试图"修正"
- stock_data.json 只读不写, 不受其他源下载覆盖
- 腾讯 fqkline 必须带 User-Agent 请求头且用 count-only 形态 (区间形态 count 会截断且不含当日)

**Why:** mootdx 量比偏差导致3年回测从盈利变成-99.8%; baostock 当日延迟反复打断盘后流水线
**How to apply:** 每次回测前确认数据源, 新增数据源前做5只股票×5个日期的交叉验证; 若需回退 baostock 版本, git 历史 6644f96 之前的 update_data.py 即为 baostock 版
