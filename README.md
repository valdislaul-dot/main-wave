# 主升浪 — A股涨停板量化交易系统 v2.1

基于 T+1 竞价判断的短线打板策略，模型选股取代人工选股。

## 回测结果 (200k 初始, 2026-03-03 ~ 2026-07-24)

| 指标 | 数值 |
|------|------|
| 最终资产 | 1,373,270 |
| 收益率 | +586% |
| 交易笔数 | 40 |
| 胜率 | 62% |
| 最大连亏 | 3 笔 |

## 策略规则

### 选股
- 全市场 T-1 涨停股，剔除 300/301/688
- V2 多因子评分 → Top3 中选 20 日均量比最小的
- 连板 ≥2 用 5 日均量，否则用 20 日
- 买入日一字板跳过，最后交易日不买

### 买入
- T 日开盘价，全仓

### 卖出 (T+1 竞价)
- T 日涨停 + 不低开 → 持有
- T 日涨停 + 低开 → 卖出
- T 日断板 + gap < 4% → 卖出
- T 日断板 + gap ≥ 4% → 持有

### 执行
- 涨停日 → HIGH（挂涨停价限价单）
- 不涨停日 → 70%(H+O)/2 + 30% 收盘价

## 每日操作

```
盘后: python scripts/daily/run_pipeline.py
9:25: python scripts/daily/morning_check.py
9:30: 竞价区间 4%-8% 全仓买入候选
14:45: 限价单未成交 → 市价兜底
```
