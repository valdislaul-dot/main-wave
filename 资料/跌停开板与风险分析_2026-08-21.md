# 跌停开板与跌停风险分析（2026-08-21）

> 数据源: 本地K线 3,045 只（2023-08-19 ~ 2026-08-19，3年，剔除300/301/688/8/9）
> 样本: 触跌停 21,558 次 | 买入池(竞价4-8%) 17,875 笔
> 脚本: scripts/limit_down_analysis*.py / dt_probability_model.py / dt_risk_integrated.py
> 报告: logs/limit_down_analysis*.txt / dt_probability_model.txt / dt_risk_integrated.txt

## 一、跌停开板基础数据

- 盘中触跌停 → 当日开板率 **39.3%**；地天板 **0.7%**（157次/3年，年均52次）
- 跌停开盘 → 开板率 **30.1%**（69.9%封死）；收盘分布: 封死69.9% / 反弹≥6% 11.7% / 地天1.8%
- 开板 vs 封死的次日: 开板-0.58%(48%涨) vs 封死-2.10%(35%涨)，各背景一致成立

## 二、五大关键维度（v3 补齐）

| 维度 | 核心发现 |
|------|----------|
| 连续跌停状态 | 首个36.3% → 第4+个 **62.4%** 开板，且第4+个次日-0.48%(52%涨)——超跌反抽模式真实存在 |
| 量能（最强） | **缩量<0.5x 开板率仅1.0%**、次日-5.45%；放量2-4x 60.1%；巨量≥4x 64.6% 但次日-2.57% |
| 时间结构 | 开盘即触开板率30.1%(次日-3.10%) vs 盘中才触40.5%(-1.29%) |
| 市场环境（反直觉） | 强市开板率83.7%但**次日-3.51%最差**(强市跌停=真利空)；弱市31.9%但次日-1.57%(情绪错杀) |
| 价格区间 | 信息量低，非关键维度 |

关键交互: 开盘触+缩量<1x → 开板率8.8%(死亡组合)；开盘触+放量≥3x → 77%(撬板主力场景)

## 三、连板背景分层（v2）

| 背景 | 触跌停 | 跌停开→开板率 | 地天率 | 次日均收益 |
|------|--------|--------------|--------|-----------|
| 前日未涨停 | 19,263 | 30.4% | 0.4% | -1.29% |
| 前日首板 | 928 | 29.2% | 1.1% | -2.89% |
| 前日2板 | 546 | **40.9%** | 2.9% | -2.68% |
| 前日3板 | 337 | 37.0% | 3.9% | -4.13% |
| 前日4板+ | 484 | **18.4%** | **7.0%** | -4.18% |

- 高位(≥4板)跌停开撬板概率最低(18.4%)、封死后次日-5.75%——跌停开应竞价跑
- 2板背景撬板率最高(40.9%)——「等自救」最佳场景
- 地天率随板数单调上升: 0.4%→7.0%（4板+是未涨停的17.5倍）

## 四、T+1跌停概率预测模型

**模型A**（T日买入池 → T+1触跌停率，基线5.3%）:
- T日板数: 未涨停2.1% / 首板8.3% / **2板18.2% / 3板+34.6%**
- T日量比: **巨量≥4x 9.5%** / 缩量<1x 4.1%
- T日封板8.6% > 炸板4.1%（封板股高位获利盘踩踏更重）
- ⚠ A4(T日状态×T+1竞价gap)含未来信息+机械相关性，仅限T+1早晨持仓评估用，不能用于T日买入决策

**模型B**（已触跌停 → 开板率）:
- 跌停开35.2% / 深水36.2% / 低开38.7% / 微低开42.0% / 平开高开50.0%
- T日状态和量能对开板率影响小(38-42%)

## 五、综合评估 — 全路径积分模型（T日可用单一数字）

P(触跌停) = Σ_gap P(gap|T特征) × P(触|T特征,gap)；P(触且封死) = P(触)×(1-条件开板率)
风险期望 = P(触且封死)×封死T+1亏 + P(触且开板)×开板T+1亏

| T日状态 | P(触跌停) | P(触且封死) | 不触时收益 | **跌停风险期望** |
|---------|-----------|-------------|-----------|-----------------|
| 缩量<1x | 4.1% | 2.5% | +2.95% | **-0.28%**（最安全） |
| 首板 | 10.7% | 5.5% | +7.07% | -0.42% |
| 平量1-4x | 4.9% | 2.9% | +0.49% | -0.47% |
| 2板 | 22.0% | 14.6% | +8.59% | -0.81% |
| 巨量≥4x | 9.5% | 5.7% | -0.58% | -0.92% |
| 3板+ | 30.5% | 18.5% | +10.59% | -0.93% |
| 炸板(高开未涨停) | 11.0% | 6.9% | -3.94% | **-1.56%**（最差） |

核心结论:
1. **炸板入口全路径皆亏**（宝泰隆型）: 次日70.3%低开/深水，不触也-3.94%——竞价4-8%买炸板股=接飞刀
2. 缩量入口最安全: 触跌停仅4.1%、次日竞价窗28.8%全场最高
3. 高位板风险奖赏结构: 3板+触且封死18.5%(每5笔1笔)，但不触+10.59%
