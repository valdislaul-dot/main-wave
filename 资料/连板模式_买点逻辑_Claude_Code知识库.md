# 连板模式：买点逻辑知识库

## 0. 使用边界（比卖点知识库更严格）

本知识库整理自一份**个人付费干货**（作者自述「过去给自己定规矩时总结」），其中同时包含：

1. **可查证的交易所事实规则**（价格笼子）—— 已按官方规则纠正原文错误；
2. **经验阈值**（7% 分水岭、低吸 -7%/-10%）—— **未经回测验证**，作者本人也承认「只是笼统定义」；
3. **纯认知层内容**（打板）—— 作者自认「没有理解力之前没有确定性」。

Claude Code 在分析、回测或生成规则时，必须：

1. **先做可信度分级**，不得把经验阈值当成铁律；
2. **价格笼子等事实规则以交易所官方口径为准**，不采用原文的简化/错误说法；
3. **未回测阈值只能作「参考提示」，不得写入自动交易逻辑**；
4. 不违反「评分因子冻结（N≥50）」和「盘中执行由用户人工执行」两条既定原则。

> 风险提示：本资料是对给定材料的知识工程化整理，来源为个人经验分享，不构成投资建议，也不保证规则在未来市场中有效。

## 1. 一句话总纲

**买点按介入时点分三类：确定性买点（打板）、半路买点（7% 分水岭）、低吸买点（参考开盘价）。现有模型是竞价买入（9:25、gap 4%-8%），本文档的盘中买点是对「竞价没买到 / 开盘后决策」的补充，不是对竞价买入的替代。**

## 2. 买点三分类

### 2.1 确定性买点 = 打板（涨停价介入）

- 冲板是最强体现，在强势时介入；
- 但**早盘半小时交投最活跃，早盘的板很多是「虚晃一枪」**：高开后资金稍作引导就易冲板，封板却需要大量资金；
- 不懂「为什么能冲板」（情绪、板块强度、个股地位）的人打板 = 赌大小；
- **工程化判断：来源自认「没有高理解力之前无确定性、无性价比」，因此不转化为自动规则。**

### 2.2 半路买点 = 7% 分水岭

- 半路 = 价格上涨过程中介入，没有明确价格；
- 活跃票的「冲板预期」以 **7% 为分水岭**：
  - 拉直线的票冲不过 7% → 大概率是假拉升 / 试盘；
  - 拉到 5%-6% 拐头向下 → 接近 7% 就有人跑，常见「骗炮」；
  - 过了 7% 才可能进入游资/量化的点火视野。
- **交叉验证（强）**：此 7% 与「卖点引擎 `weak_to_strong.surge_pct = 7.0`」及「卖点知识库的 7% 线（烂板/炸板后快速修复确认门槛）」三源一致。
- **新视角**：7% 不止是卖出侧的「真转强确认」，也是**买入侧**的「半路追涨分水岭」。
- 来源说明：主要适用于连板。

### 2.3 低吸买点 = 参考开盘价（未回测）

低吸 = 下跌过程中介入，位置要够低，不确定性大（低吸错了次日本身有低开预期）。

分两小类：

| 小类 | 参考位 | 场景 |
|---|---|---|
| ①开盘低吸 | **开盘价 -7%** | 高开后急速下杀（如高开 5% 杀到 -2%），一根线杀出恐慌盘，下杀充分后多数出现理性回归修复 |
| ②盘中低吸 | **开盘涨幅 -10%** | 高开后大幅下杀、震荡到水下，博弈日内/次日修复 |

① 和 ② 叠加看：开盘给了低吸点没把握到，后面想低吸再看 ②。

**可信度：低**。无回测数据，作者自述「7% 只是笼统定义，低吸要下杀幅度够大才有博弈点」。**只做参考提示，标注「未经回测验证」。**

### 2.4 早盘模式的简化总结（来源原话）

```text
开盘拉升 → 半路 B
开盘砸到 0 轴 / 水下 → 低吸 B
早盘没看到又想低吸博弈 → 开盘价 -7% 或 -10% B
无脑 B（开盘就下班）→ 看个人胜率
```

## 3. 价格笼子机制（已按官方规则纠正）

原文说「现价 10 元最高挂 10.2、最低挂 9.8」，**这是错的**。准确规则（沪深交易所，全面注册制后）：

### 3.1 连续竞价阶段

- 买入限价申报 ≤ **买入基准价格 × 102%**
- 卖出限价申报 ≥ **卖出基准价格 × 98%**
- **基准价格是「对手方最优申报价」**：
  - 买入基准 = 最低卖出申报价（**卖一价**）；无卖一时 = 最新成交价；无最新成交价 = 前收盘价；
  - 卖出基准 = 最高买入申报价（**买一价**）；无买一时 = 最新成交价；无最新成交价 = 前收盘价。
- 超出即废单。

### 3.2 集合竞价阶段

- 集合竞价（9:15-9:25）申报受涨跌停范围约束（主板 ±10% 等），可挂涨停价/跌停价（原文「竞价期可挂涨跌停」这一点正确）；
- 9:25 撮合出开盘价后、9:30 进入连续竞价，此时起才严格按上述 102%/98% 笼子约束。

### 3.3 对工程化的影响

- 现有模型是 9:25 竞价买入，竞价期挂单不受 102%/98% 连续竞价笼子限制；
- 但若 9:25 后（含 9:30 开盘）才补单，挂单价必须遵守「对手方最优价 ×102%/98%」，**用「现价±2%」算会算错基准**；
- 腾讯行情里卖一/买一价可用于精确计算笼子价（注意代码字段索引）。

## 4. 与现有模型的结合点（工程化边界）

| 内容 | 结合方式 | 是否自动交易 |
|---|---|---|
| 7% 分水岭 | 盘中「半路追涨」观察提示（与卖点引擎 7% 同源） | 否，仅提示 |
| 价格笼子 | 执行提醒：9:25 后补单按卖一×102%/买一×98% 计算，防废单 | 否，仅提醒 |
| 低吸 -7%/-10% | 参考观察提示，标注「未经回测验证」 | 否，仅提示 |
| 打板 | 不落地（来源自认无确定性） | 否 |

## 5. 来源未明确、不得擅自硬编码的参数

1. 7% 分水岭是经验阈值，不是交易所规则；
2. 低吸 -7% / -10% 为作者个人阈值，无回测依据；
3. 「高开 5% 以上可翻绿低吸」中的 5% 未给出严格定义；
4. 价格笼子的准确规则以交易所官方口径为准，不采用原文的「现价±2%」。
